# 装备系统

> 文件：`scripts/prefabs/mushasword*.lua`, `armor_musha*.lua`, `hat_m*.lua`, `phoenixspear.lua`, `frosthammer.lua`, `bowm.lua`, `pirateback.lua`

## 系统特点

- 所有 Musha 专属装备拥有**独立等级系统**，通过使用积累经验
- 等级通过 `OnSave`/`OnLoad` 持久化
- 装备满级显示 "MAX"
- 燃料耗尽时进入"破损"状态（伤害降至 1）
- 通过 `characterspecific_musha` 组件限制仅 Musha 可使用

### 武器耐久与损耗

专属武器仍使用旧的大数值 `fueled` 耐久池：常规武器为 `30000000`，冰霜锤为 `40000000`。创建后都会调用 `StopConsuming()`，因此普通装备、放在手上或打开弓容器不会按时间自然损耗耐久。

实际耐久损耗主要发生在攻击命中回调里：每次有效攻击按随机档位扣除 `150000`、`75000`、`35000` 或 `20000` 耐久。火焰剑和冰霜剑的右键强化额外每秒扣 `50000` 耐久，开启前会检查 `not inst.boost`，关闭、卸下或耐久耗尽时会取消任务，当前没有重复开启导致越扣越快的风险。

弓和终极剑的毒伤/吸血效果使用短周期任务表现持续伤害；这些任务必须在持续时间结束、目标死亡或毒标签消失时取消，否则旧任务会留在世界上，目标下次再次中毒时一起触发，表现为持续伤害越来越快。当前代码已改为保存任务句柄并在结束时取消。

装备经验 >= 3000 且未破损时，部分武器获得位面伤害：凤凰长剑（含蓝色铲形态）和凤凰斧为 35，火焰剑和冰霜剑为 30，冰霜锤为 50。破损后会移除位面伤害，修复或读档后按当前经验重新刷新。

### 护甲耐久与损耗

护甲类装备仍使用 `fueled` 组件保存可修复耐久，但数值已改为接近 DST 原生护甲的可读耐久值：`7700`、`6417` 或 `8214`。同时会把原版 `armor` 组件的耐久上限和当前值同步到这组数值，避免属性 Mod 读取到旧的超大 `1e+050` 耐久。受击时不再按旧的 `defaultdamage` 分档扣几万到几百万燃料，而是按 DST 原生护甲思路扣除耐久：`原始伤害 * 当前护甲吸收率`，最少扣 1 点。升级提供的吸收率仍由各装备 `UpgradeArmor` 中的 `EquipUtils.InitArmorFromFuel(..., absorb)` 控制。

普通穿戴不再启动 `fueled` 的时间消耗；耐久主要由受击扣除，冰霜护甲/公主冠等主动护盾效果保留每秒耐久消耗。第三方属性 Mod 可能仍会因为检测到 `fueled` 组件而显示“燃料持续时间”，这是兼容显示，不代表普通穿戴会按时间掉耐久。

右键主动模式通过显式 `DoPeriodicTask` 消耗耐久，并在重新开启前取消旧任务，避免重复触发后损耗越来越快。当前主动消耗为：冰霜护甲护盾 `5/秒`、公主冠护盾 `5/秒`、凤凰冠 `4/秒`、兔耳帽/兔耳帽A/野猫耳右键模式 `4/秒`。

右键修复保持原比例：常规修复约恢复 `1283` 点耐久；经验物品和锻造台对新护甲耐久池分别恢复 `1283` 和 `642`，对仍使用旧大燃料池的武器保持原数值。

### 破损冰锤 (Broken Frost Hammer)

| 属性 | 值 |
|------|------|
| 预制件 | `broken_frosthammer` |
| 说明 | 冰锤护甲形态（蝶翼盾） |
| 防雨 | 80% |

冰霜护甲同时承担右键防御和小型冰箱职责，使用独立的 8 格 `frostsmall` 小冰箱容器，不再复用普通 `backpack` 容器逻辑。冰箱效果通过装备自身的 `preserver` 组件提供，保鲜倍率为 10 倍（腐烂速度 0.1），只影响冰霜护甲容器内物品，不给玩家主物品栏附加冰箱效果。

冰霜护甲 prefab 入口仍在 `scripts/prefabs/broken_frosthammer.lua`。容器打开/关闭音效、格挡音效、右键防御开启/关闭、护盾燃料消耗和理智消耗等辅助逻辑集中在 `scripts/musha/prefabs/frost_armor.lua`；等级成长、耐久结算、冰冻反击和保存字段仍由 prefab 入口编排。冰霜护甲在装备经验 >= 3000 时额外提供 15 位面防御。

额外装备栏兼容由 `scripts/musha/equipment/inventory_overflow.lua` 单独处理。当前策略不再劫持拾取、制作产物或 `shift-click` 分拣；只控制冰霜护甲容器显示：穿上或打开额外背包会自动关闭小冰箱，关闭或卸下额外背包后如果冰霜护甲仍穿着则重新打开。该逻辑只识别 `broken_frosthammer` 和 `BACK`/`PACK`/`BACKPACK`/`BAG` 等额外背包槽。
